# Gimi · quirky-sketch 校准图

> **不是 IP 设定图。** 与 `reference-character.png` 配对使用，告诉模型：怪诞手绘里 Gimi 仍长这样。

## 协议（见 `references/ip/gimi/ip.md`）

每次 `$IP=gimi` 生图：**设定图 + 本目录 1 张校准图**（共 2 张）。

校准图**只做一件事**：sketch 风格下的正确 Gimi（锚点、比例、配色）。不抄场景、不抄构图、不抄标注。

## 风格正向案例

| 文件 | 校准用途 | 选用时机 |
|------|---------|---------|
| `gimi-writing-rules-checklist.png` | 全身锚点 + sketch 质感 + 标注范例 | **默认**；拿不准、需看清锚点时 |
| `gimi-desk-shoulder-fatigue.png` | 环境暗示 + 伏案情绪 + 职场场景 | 职场 / 久坐 / 痛点 / 环境类 |
| `gimi-exercise-modal-focus.png` | 信息聚焦 + UI 弹窗 + 产品界面 | 产品界面 / 弹窗 / 功能讲解 |
| `gimi-ai-change-chaos.png` | 情绪 + AI 介入 + 顶标题 | AI 改文件 / 焦虑 / 有图内标题 |

跑出新满意图 → 可替换或增补上表，保持本目录 ≤4 张活跃案例。
